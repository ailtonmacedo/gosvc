8. Quickstart

gosvc doctor --preset postgres-api
gosvc new catalog-service \
  --module github.com/acme/catalog-service \
  --preset postgres-api
cd ../catalog-service
make bootstrap
gosvc doctor --project .
docker compose up -d postgres
export DATABASE_URL='postgres://postgres:postgres@localhost:5432/catalog-service?sslmode=disable'
make migrate-up
make verify
make run
cd framework-go/gosvc
make build VERSION=dev
./bin/gosvc doctor --preset postgres-api
./bin/gosvc new catalog-service \
  --module github.com/acme/catalog-service \
  --preset postgres-api
cd ../catalog-service
make bootstrap
../gosvc/bin/gosvc doctor --project .
Omitir --preset-version escolhe a versão current para o projeto novo. A CLI imprime o valor resolvido e o persiste.

9. Bare e Worker

bare

App scaffold sem HTTP/banco. Real E2E executa app smoke; OpenAPI/sqlc são N/A.

worker

Long-running context-aware process. Real E2E confirma startup/liveness e encerramento controlado.

  go:
    language: 1.25.0

Quando coverage é N/A?

O script filtra apenas statements em internal/domain, internal/application e internal/infrastructure/http. Se o profile filtrado tiver só o header e zero statements, retorna N/A. Assim que existir statement monitorado, o threshold (80% default) passa a valer.

25. Upgrade de preset

# preview
 gosvc upgrade --project . --preset-version 1.1.0 --dry-run

# apply + automatic backup
 gosvc upgrade --project . --preset-version 1.1.0

# rollback
 gosvc upgrade rollback --project . --backup latest --dry-run

Em um upgrade explícito de versão, `project.yaml` pode ser canonicalizado porque a mudança do contrato de configuração foi solicitada pelo usuário. Outros arquivos user-owned permanecem protegidos.
